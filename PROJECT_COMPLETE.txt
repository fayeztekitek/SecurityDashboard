PATH 2: SETUP GITHUB REPOSITORY
──────────────────────────────────
1. Follow GITHUB_SETUP_INSTRUCTIONS.txt
2. Create repository on GitHub
3. Clone repository locally
4. Push all files to GitHub
5. Configure branch protection & settings
6. Add team members
7. Start development workflow

Time: 30 minutes
Setup: GitHub account required

PATH 3: AUTOMATE FORTIFY EXPORT
────────────────────────────────
1. Install Python: pip install requests python-dateutil
2. Get Fortify API token from https://soft-security.vermeg.com/ssc/
3. Run: python3 extract_fortify_data.py \
          --fortify-url https://soft-security.vermeg.com/ssc \
          --token YOUR_TOKEN \
          --output vulnerabilities.csv
4. Open consolidated_dashboard.html
5. Import generated CSV

Time: 10 minutes
Requirements: Python 3.8+, Fortify access
