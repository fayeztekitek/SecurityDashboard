================================================================================
GETTING GITHUB AUTHENTICATION
================================================================================

FOR HTTPS METHOD (Recommended):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Generate Personal Access Token:
1. Go to: https://github.com/settings/tokens/new
2. Login if prompted
3. Give token a name: "Dashboard Push"
4. Select scopes:
   ✓ repo (Full control of repositories)
   ✓ workflow (Update GitHub Actions workflows)
5. Click "Generate token"
6. COPY TOKEN IMMEDIATELY (you won't see it again!)
7. Save in secure location (password manager)

Using Token:
- When git asks for "Password", paste the token
- Token acts as your password for HTTPS cloning
- Keep token secure, treat like password

FOR SSH METHOD (Recommended for Long-term):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Generate SSH Key (if you don't have one):
1. Open Terminal
2. Run: ssh-keygen -t ed25519 -C "your@email.com"
3. Press Enter for default location
4. Enter passphrase (optional but recommended)
5. Key created at ~/.ssh/id_ed25519

Add SSH Key to GitHub:
1. Copy public key: cat ~/.ssh/id_ed25519.pub
2. Go to: https://github.com/settings/ssh/new
3. Title: "Dashboard Dev"
4. Paste key and save

Using SSH:
- Use URL format: git@github.com:username/repo.git
- No password prompt (unless passphrase set)
- More secure for long-term use

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: "fatal: not a git repository"
SOLUTION:
   Make sure you're in the right directory with the dashboard files
   Run: git init
   Then: git remote add origin https://...

PROBLEM: "Authentication failed" or "Access denied"
SOLUTION:
   ✓ For HTTPS: Verify Personal Access Token is correct (not your password)
   ✓ For SSH: Verify SSH key is added to GitHub (Settings > SSH Keys)
   ✓ For SSH: Verify SSH is configured: ssh -T git@github.com
   ✓ Verify repository URL is correct
   ✓ Verify you have access to the repository

PROBLEM: "Repository not found"
SOLUTION:
   ✓ Verify GitHub repository is created
   ✓ Verify repository name in URL is correct
   ✓ Verify you have access (private repo needs permissions)
   ✓ Verify URL format:
      HTTPS: https://github.com/username/repo.git
      SSH: git@github.com:username/repo.git

PROBLEM: "Permission denied (publickey)"
SOLUTION:
   ✓ SSH key not configured properly
   ✓ SSH key not added to GitHub
   ✓ Try: ssh -T git@github.com (should show your username)
   ✓ Re-add SSH key to GitHub (Settings > SSH Keys)
   ✓ Or use HTTPS method with Personal Access Token instead

PROBLEM: "refusing to merge unrelated histories"
SOLUTION:
   You may have initialized GitHub repo with README
   ✓ Go to GitHub > Settings > Danger Zone
   ✓ Delete repository
   ✓ Create new empty repository (no README)
   ✓ Try again: git push -u origin main

PROBLEM: "rejected ... (fetch first)"
SOLUTION:
   Repository has content from GitHub that's not local
   ```bash
   git pull origin main --allow-unrelated-histories
   git push origin main
   ```

FREQUENTLY ASKED QUESTIONS
================================================================================

Q: Can I undo a commit?
A: Yes, if not pushed: git reset --hard HEAD~1
   Or if pushed: git revert COMMIT_HASH

Q: Can I delete my GitHub repository?
A: Yes, Settings > Danger Zone > Delete repository
   Then create a new one and push again

Q: Can I make the repository public?
A: Yes, Settings > General > Change to Public
   (Make sure no sensitive data is committed)

Q: How do I add more collaborators?
A: Settings > Collaborators and teams > Add people
   Send them the repository URL

Q: Can I rename the repository?
A: Yes, Settings > General > Repository name
   Then update local remote: git remote set-url origin NEW_URL

Q: Where is my git password stored?
A: On Mac: Keychain
   On Windows: Credential Manager
   On Linux: Git credential helper
   Delete with: git config --unset user.password
